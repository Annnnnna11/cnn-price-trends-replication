# I20/R20 逐年结果、主表与补充表解读

## 口径

所有结构固定使用 1993—1999 训练／验证后的最佳权重，不按测试年份重新训练。下列年份为图像结束日／组合形成日期年份，不是统一按收益实现日期分组。
分类按 Ret_20d 标签；金融按 Ret_month。每结构均为五成员等权概率融合，阈值固定 >0.5。
原始输入与原结果保持不变；本目录的年度文件仅是描述性拆分，没有根据年度表现重新选择模型。

## 主表、补充表究竟指什么

第一组含义来自原论文：PDF 第 19 页的正文 Table 2 报告等权 EW 的月度与季度组合；本项目对应其上半部分的 I20/R20 列。
PDF 第 55 页的 Internet Appendix Table IA3 报告市值加权 VW 的相应组合。同样看上半部分 I20/R20 列。表中 Ret 为年化平均持有收益、SR 为 Sharpe，Low/High 是预测上涨概率最低／最高的十等分组，H-L 是 High-Low。论文另有显著性星号和换手，本项目没有重算这些，不能沿用其星号。

第二组含义来自当前报告的时间段：`course_2000_2019` 为课程主测试形成年份；`common_2001_2019` 为预先声明的共同年份补充，不是第二套模型，也不是重训后结果。两个时间段各有 EW/VW；不能把“补充年份”与“附录中的 VW 表”混为一谈。

|I20/R20、H-L|EW 年化算术均值|EW Sharpe|VW 年化算术均值|VW Sharpe|
|---|---:|---:|---:|---:|
|原论文 2001—2019，训练／验证 1993—2000|约21.00%|2.16|约5.00%|0.49|
|本项目三层主区间 2000—2019，训练／验证 1993—1999|23.33%|1.701|5.74%|0.487|
|本项目三层共同年份 2001—2019，训练／验证 1993—1999|19.60%|2.180|4.58%|0.416|

相同测试年份仍不代表训练条件相同；论文数字经过四舍五入，仅作描述性对照。不能只选择看起来最接近论文的区间宣称严格复现成功。
去掉 2000 形成年份后，三层 EW 年化波动从 13.71% 降到 8.99%，收益均值也从 23.33% 降到 19.60%，但波动下降比例更大，Sharpe 因而提高。
2000 形成年份包含 2000-12-29 对应至 2001 年 1 月的单月 H-L +44.995%；共同年份筛选会连同这笔收益一起排除，不是简单删掉自然年 2000 的已实现收益。

常涨、常非涨是两个预先定义的固定分类规则。事后取二者较高值仅用于诊断类别不平衡，不能当成事先知道今年市场方向的可部署策略，也没有用于选择模型。2008 年常非涨为 62.664%，四层准确率 57.365%；因此“超过 50%”不充分。

所有结构逐年 AUC 均高于 0.5，说明观察到持续但有限的排序信号；没有显著性检验，不能把小幅高于 0.5 写成显著或强预测能力。
三层只有 10/20 年超过常涨，4/20 年同时超过两个恒定类别参考。它的 AUC/MCC 较高与这一点并不矛盾：排序与固定阈值分类回答不同问题。

二层预测上涨类别的比例在每年都高于三层，四层则每年都低于三层。整体比例分别为 58.35%、49.15%、41.86%。这种阈值下的类别倾向与各年真实上涨占比变化共同影响准确率。
2003 年上涨占比 65.25%，二层相对较好；2008 年非上涨占比较高，四层相对较好。这是描述性关联，不是证明网络识别某一市场状态的因果机制，也不授权按事后年份挑结构。

## 每年的具体解读


**2000：** 四层分类相对最好，三者均超过两个恒定类别参考；三层 EW 年化均值很高，但包含一个 +44.995% 的单月 H-L，风险同样很大。 三层 CE=0.687418，AUC=0.5577，MCC=0.0810；三层 EW/VW 年化算术均值分别为 +93.82% / +27.68%。

**2001：** 三个结构准确率接近，AUC 约 0.52；CE 均高于 ln(2)。三层 EW 较高，VW 接近零，不能用等权结果代表所有权重。 三层 CE=0.693421，AUC=0.5219，MCC=0.0254；三层 EW/VW 年化算术均值分别为 +47.33% / +0.14%。

**2002：** 四层 CE、准确率与 AUC 在结构间较好；但准确率仍低于恒定非上涨参考。EW/VW 均为正。 三层 CE=0.690027，AUC=0.5395，MCC=0.0546；三层 EW/VW 年化算术均值分别为 +26.06% / +3.19%。

**2003：** 上涨样本占 65.25%，三者均低于 always-up；四层准确率低于 50%，但 AUC 仍约 0.5445。三层 EW 为负、VW 略正。 三层 CE=0.694259，AUC=0.5444，MCC=0.0570；三层 EW/VW 年化算术均值分别为 -3.31% / +0.73%。

**2004：** 二层 CE 与准确率较好，但仍低于 always-up；三层 AUC 较高，EW 与 VW 的年化均值均为正。 三层 CE=0.691642，AUC=0.5363，MCC=0.0485；三层 EW/VW 年化算术均值分别为 +22.64% / +10.57%。

**2005：** 三个结构均未超过 always-up，AUC 仍高于 0.5。三层 EW 为正、VW 为负，金融结果依赖股票权重。 三层 CE=0.692228，AUC=0.5366，MCC=0.0544；三层 EW/VW 年化算术均值分别为 +17.16% / -6.24%。

**2006：** 二层准确率略高于三层且超过 always-up；三层 AUC 较高。这一年不能只按准确率给全部指标排名。 三层 CE=0.689095，AUC=0.5537，MCC=0.0779；三层 EW/VW 年化算术均值分别为 +7.52% / +2.88%。

**2007：** 三、四层准确率相近且均低于恒定非上涨参考；三层 AUC 在结构间较高，EW/VW 年化均值均为正。 三层 CE=0.691872，AUC=0.5318，MCC=0.0459；三层 EW/VW 年化算术均值分别为 +22.16% / +6.28%。

**2008：** 四层在 CE、准确率及 AUC 上较好；但 62.66% 样本为非上涨，三者准确率均低于 always-nonup。排序信号与 EW/VW H-L 仍为正。 三层 CE=0.684452，AUC=0.5660，MCC=0.0942；三层 EW/VW 年化算术均值分别为 +54.70% / +28.03%。

**2009：** 上涨样本较多，二层准确率较高，但三者均低于 always-up。三层 EW 为正、VW 为负，不能把概率排序与所有组合收益混为一谈。 三层 CE=0.690624，AUC=0.5360，MCC=0.0522；三层 EW/VW 年化算术均值分别为 +20.61% / -6.07%。

**2010：** 二层准确率达到 56.00%，但 always-up 更高，为 60.78%；三层 AUC 仍高于 0.5，EW/VW H-L 为正。 三层 CE=0.687759，AUC=0.5439，MCC=0.0562；三层 EW/VW 年化算术均值分别为 +15.49% / +13.94%。

**2011：** 四层 CE 与准确率较好，但仍低于恒定非上涨参考。三层 EW 与 VW 年化均值均较高。 三层 CE=0.691533，AUC=0.5303，MCC=0.0406；三层 EW/VW 年化算术均值分别为 +35.39% / +13.17%。

**2012：** 二层 CE 与准确率相对较好，但三者均低于 always-up。三层 EW 为正、VW 为负，优势不跨权重一致。 三层 CE=0.694509，AUC=0.5176，MCC=0.0230；三层 EW/VW 年化算术均值分别为 +14.57% / -3.99%。

**2013：** 三层 AUC 仅约 0.5070，三个结构 EW/VW H-L 均为负，是必须展示的失败年份。二层准确率较高也未超过 always-up。 三层 CE=0.695017，AUC=0.5070，MCC=0.0060；三层 EW/VW 年化算术均值分别为 -4.02% / -2.20%。

**2014：** 三、四层准确率几乎一致，四层 CE/AUC 略好；三者均超过两个恒定类别参考。三层 EW 为正、VW 为负。 三层 CE=0.688402，AUC=0.5536，MCC=0.0757；三层 EW/VW 年化算术均值分别为 +10.80% / -5.50%。

**2015：** 二层准确率低于 50%，三层 AUC 约 0.5180，排序信号较弱；但三层 EW/VW H-L 均为正，说明方向分类与收益幅度评价并不相同。 三层 CE=0.695035，AUC=0.5180，MCC=0.0233；三层 EW/VW 年化算术均值分别为 +26.87% / +20.23%。

**2016：** 二层 CE 与准确率较好，三层 AUC 较好；三者均低于 always-up。三层 EW 为正、VW 为负。 三层 CE=0.691563，AUC=0.5322，MCC=0.0465；三层 EW/VW 年化算术均值分别为 +7.77% / -2.75%。

**2017：** 二层准确率相对较高，三层 AUC 较高；三者均低于 always-up。三层 EW/VW 年化均值均为正。 三层 CE=0.692892，AUC=0.5240，MCC=0.0318；三层 EW/VW 年化算术均值分别为 +10.15% / +4.09%。

**2018：** 四层准确率略高，二层 AUC 较高；三者均低于恒定非上涨参考。三层 EW/VW 年化均值均为正。 三层 CE=0.694406，AUC=0.5199，MCC=0.0301；三层 EW/VW 年化算术均值分别为 +24.52% / +12.38%。

**2019：** 二层 CE 与准确率较好，但三者均低于 always-up。三层 EW 为正、VW 为负；金融只有 11 个形成月份，年化均值不是完整自然年实得收益。 三层 CE=0.691673，AUC=0.5275，MCC=0.0376；三层 EW/VW 年化算术均值分别为 +15.66% / -2.52%。

## 可以用于正文的结论

1. 三种结构在各测试年份均呈现 AUC>0.5 的有限排序信号；固定阈值准确率的优势不跨年份一致。
2. 二层更轻量，整体 CE／Accuracy 略好；三层整体 AUC／MCC 和 VW Sharpe 较好；四层 EW Sharpe 小幅提高，没有全面改善。
3. 概率损失、方向准确率、收益排序与金融表现不可互相替代，2003、2008、2013、2015 是有解释价值的例子。
4. EW 结果比 VW 更强；2013 年为共同失败年份；2000 年的极端月收益明显影响风险调整指标，必须保留并说明。
5. Grad-CAM 展示固定 seed101 对具体样本的类别分数支持区域，不是融合解释，不证明价格形态或收益的因果关系。
