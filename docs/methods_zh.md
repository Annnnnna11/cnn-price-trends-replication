# 数据、模型与评价口径

## 任务与数据

|项目|本次设置|
|---|---|
|输入|过去 20 个交易日的 OHLC、均线、成交量图像，单通道 64×60|
|目标|`Ret_20d > 0` 为 1，非正为 0；缺失收益不作为第三类训练|
|训练／验证范围|1993—1999；训练池排除 `Date >= 1999-12-01`，并要求有效收益及正的有限 EWMA 波动率|
|训练／验证划分|seed 101—105 各自随机 70/30；每次训练 477,059，验证 204,455|
|测试范围|2000—2019；补充报告共同年份 2001—2019|
|标准化|像素先除以 255；每个 seed 只从其训练样本估计全局均值与标准差|
|测试输入筛选|正的有限 EWMA 波动率；生成预测时不要求未来收益可观测|
|分类评价筛选|合格输入、有限预测、有限 `Ret_20d`|

五次划分互有重叠，属于重复随机划分，不是五折交叉验证。二／四层逐 seed 复用三层划分和标准化。随机种子编号是本实验配置，未认定为论文指定编号。

原论文使用 1993—2000 年训练／验证、2001—2019 年测试；课程给定 1993—1999、2000—2019，按课程执行。共同年份补充不能消除训练年份不同等差异。

## 网络与训练

每块执行 Conv2d → BatchNorm → LeakyReLU → MaxPool。卷积核 5×3、padding 2×1；第一块 stride 3×1、dilation 2×1，后续块为 1×1。MaxPool 为 2×1、ceil mode；LeakyReLU 负斜率 0.01。展平后 Dropout 0.5，再线性映射到两个 logits。

|设置|值及作用|
|---|---|
|通道数|二层 64/128；三层增加 256；四层再增加 512|
|初始化|Xavier 初始化；未使用预训练权重|
|优化器|Adam，学习率 1e-5，betas 0.9/0.999，epsilon 1e-8，weight decay 0|
|批量|128；每个 epoch 遍历全部训练样本|
|目标函数|交叉熵，使用两个原始 logits；验证时不更新参数|
|最佳轮|验证 CE 严格降低时更新最佳检查点|
|停止|连续 2 轮不改善或达到 50 轮|
|数值与加载|float32，无 AMP/TF32，workers=0，4 CPU 线程|
|融合|五个最佳模型的上涨概率算术平均，每个权重 0.2|
|分类阈值|上涨概率严格大于 0.5；等于 0.5 判为非上涨|

结构扩展同时改变深度、通道数和参数量，不能解释为参数匹配的纯深度因果实验。Smoke test 仅检验流程可运行，不为正式模型提供初始权重。

## 评价

分类报告 CE、Accuracy、MCC、Balanced Accuracy、ROC AUC 和 Brier；常数基准包含训练上涨比例概率、always-up、always-nonup。五个成员验证集不同，不能直接把验证预测按行平均；测试使用相同输入，可进行概率融合。

金融评价按每个形成日期的预测概率划分十组，分别计算等权（EW）及形成日绝对市值权重（VW）收益。H-L 为最高组减最低组，对应 100% 多头与 100% 空头。`Ret_month` 与分类的 `Ret_20d` 不同。

|统计|定义|
|---|---|
|年化算术收益|月收益均值 ×12，不是 CAGR|
|年化波动率|月收益样本标准差 ×√12，ddof=1|
|Sharpe|月均收益／月收益样本标准差 ×√12，零无风险利率|
|样本范围|正的有效绝对市值、可用后续月收益等历史完整观测样本|
|未估计|交易成本、借券费、融资成本、净收益、换手率及显著性|

收益可观测性筛选可能产生选择偏差。主区间有 239 个有效形成月份，共同区间有 227 个；2019 年只有 11 个。年度表按形成年份分组，12 月形成组合的持有收益可能到次年 1 月实现。

## Grad-CAM

使用三层 seed 101 最佳模型的验证预测定义 TP/TN/FP/FN，每组固定随机抽取 3 个案例（抽样 seed 20261118）。相同 12 张图输入各深度 seed 101 最佳模型，分别解释类别 0 与 1 的原始 logit，共 72 张热图。

目标层为最后一块的 LeakyReLU 输出、池化之前。对目标 logit 求梯度，空间平均得到通道权重，与特征图加权求和后 ReLU，再放大至 64×60 并逐图归一化。分析时启用梯度，但模型处于 eval mode，不执行优化器或权重更新。

二／三／四层原生热图为 10×60、5×60、3×60。颜色强度不代表上涨概率，也不是跨模型绝对重要性尺度；放大带来的平滑差异不能直接解释为更好的规律。结论限定于这些固定成员和案例。
